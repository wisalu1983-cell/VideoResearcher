# 转录 current spec

> 状态：R0 基线
> 来源：`video_agent_requirements_research.md` §12、§13、§15、§16、§18

## 当前承诺

V2-lite 的转录目标是为索引和追问提供带时间戳的可读文本。首版优先处理中文普通话、英文和中英混合视频。

首轮验证环境为 Windows + NVIDIA 台式机：

| 设备 | 定位 |
|---|---|
| 4070 Ti Windows 台式机 | 主力基准环境 |
| 5060 Windows 台式机 | 兼容与备用验证环境 |

## 工具链策略

转录层必须保持可替换，不应让上层索引和追问逻辑绑定到单一工具。

优先级：

| 优先级 | 方案 | 定位 |
|---|---|---|
| P0 | FFmpeg + 本地开源转录工具 | 首选路径 |
| P0 候选 | faster-whisper | Windows + NVIDIA 主力验证对象 |
| P0 候选 | whisper.cpp | 跨平台备用与迁移候选 |
| P1 | 公司模型或 API | 本地效果不足时的人工批准兜底 |
| P2 | 用户自费工具 | 最后兜底，必须人工批准 |

任何外部 API、公司模型或自费工具调用前，必须确认成本、权限和数据边界。

## 输出要求

- 生成带时间戳的 `transcript/transcript.srt`。
- 生成结构化的 `transcript/transcript.json`。
- 时间戳应支持后续片段定位。
- 个别术语错误可以存在，但不能影响整体理解。
- 1 到 3 小时视频需要支持分段处理设计。

## 质量分级

| 等级 | 含义 | 允许用途 |
|---|---|---|
| A：可精确追问 | 文本可读，时间戳能定位片段 | 可进入 V2-lite 追问闭环 |
| B：可概览 | 大意可读，但时间戳或术语存在明显风险 | 可生成摘要和大纲，追问时提示定位不精确 |
| C：不可可靠分析 | 大面积转录错误、音频严重问题或时间戳严重错位 | 停止确定性结论，保留中间结果和失败日志 |

数值阈值等待真实样本测试后再固化。

## 失败处理

- 视频文件无法读取时，提示转码或换格式。
- 音频抽取失败时，尝试 FFmpeg 转码；仍失败则停止。
- 本地转录失败时，可尝试降级模型、CPU 模式或分段重试。
- 转录质量明显差时，标记低质量转录，并建议补充字幕、音频或经人工批准使用兜底方案。
