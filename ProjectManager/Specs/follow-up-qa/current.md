# 追问 current spec

> 状态：R0 基线
> 来源：`video_agent_requirements_research.md` §5、§6、§8、§10、§11、§18

## 当前承诺

V2-lite 的追问目标是层级 2，并具备部分层级 3 能力：能基于索引检索相关片段，定位具体视频时间段，概括片段内容，说明为什么该片段支撑回答；必要时回查转录文本核对文字细节。

暂不强制支持截图、OCR、抽帧和完整画面理解。

## 回答结构

追问回答应包含：

1. 直接回答。
2. 相关视频片段时间段。
3. 片段内容概括。
4. 为什么该片段支撑回答。
5. 必要时的转录文本核对说明。
6. 依据不足或不确定性的提示。

## 依据优先级

| 优先级 | 依据 |
|---|---|
| P0 | `index/video_index.yaml` 中的章节、片段和高价值标记 |
| P1 | `transcript/transcript.json` 中的时间戳转录文本 |
| P2 | `notes/video_note.md` 中的人类阅读摘要 |
| P3 | 经边界允许的外部资料补足或校验 |

当视频内容足够回答时，优先基于视频内容回答。

## 索引回写

追问中发现以下情况时，应补充索引或记录变更：

- 用户频繁追问的主题需要提高索引权重。
- 新发现的高价值信息需要补充到索引。
- 原有判断不准确，需要修正索引并留下修改记录。
- 同一视频后续问答应继承最新筛选标准。

## 不足与失败

- 索引中依据不足时，应明确说明无法从现有索引可靠回答。
- 转录可回查时，应建议或执行转录核对。
- 时间戳质量为近似或不可靠时，回答必须提示定位风险。
- 不得编造视频中没有的内容。
