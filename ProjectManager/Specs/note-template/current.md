# 笔记模板 current spec

> 状态：R0 基线
> 来源：`video_agent_requirements_research.md` §5、§7、§9、§10、§21

## 当前承诺

`notes/video_note.md` 是人类阅读版视频笔记。首版采用混合版风格：默认帮助快速消化视频，对高价值片段保留关键线索，支持后续追问和复盘。

## 输出原则

- 用中文解释视频内容，必要时保留英文或其他语言的专业术语。
- 第一轮输出极简价值摘要和完整大纲。
- 高价值片段需要标注时间段和价值方向。
- 重要定义、方法、观点、数据保留原文要点，但不输出大段原文。
- 不把笔记写成完整逐字稿。

## 与索引的关系

- `video_note.md` 面向人类阅读。
- `video_index.yaml` 面向 Agent 和结构化检索。
- 笔记中的时间段、章节和高价值片段应能追溯到索引中的对应条目。
- 笔记可以比索引更易读，但不得引入索引和转录中没有依据的确定性结论。

## 质量分级提示

- A 档材料可生成完整笔记和追问方向。
- B 档材料可生成概览笔记，但必须提示时间戳或术语风险。
- C 档材料只保留处理状态、失败说明和可补充材料建议。
