# 外部资料 current spec

> 状态：R0 基线
> 来源：`video_agent_requirements_research.md` §5、§8、§17、§18

## 当前承诺

外部资料只用于与当前追问直接相关的补足或校验，不主动扩展到相邻话题。

## 可用场景

外部资料可以用于：

- 事实校验。
- 补足背景知识。
- 评价视频观点可靠性。
- 识别视频观点局限。

## 来源优先级

优先使用一手来源、官方文档、原始论文、权威机构、主流专业媒体。谨慎使用自媒体、搬运内容、匿名爆料和无出处二次解读。

涉及产品、政策、价格、版本、人物、事件时，需要复核时效性。单一说法不足以支撑关键结论时，应交叉验证。

## 回答格式要求

当引入外部资料时，回答必须区分：

- 视频内容怎么说。
- 外部资料补充或校验了什么。
- 两者是否存在冲突。
- 哪些结论仍然不确定。

当用户问的是“视频里怎么讲”时，应先忠实复述视频内容，再单独提示可能问题。

## 禁止与限制

- 不使用低可靠来源硬答。
- 不绕过 DRM、付费墙、私密权限或登录限制。
- 不在未获用户确认时上传私人或公司内部视频材料。
- 不把外部资料当成视频内容本身。

## 与 API 兜底的关系

公司模型、外部 API 或自费工具只作为人工批准 gate。实际调用前必须确认成本、权限和数据边界。
