# 输入与材料 current spec

> 状态：R0 基线
> 来源：`video_agent_requirements_research.md` §3、§12、§14、§17

## 当前承诺

首版主链路以本地材料为基础。V2-lite 必须支持本地视频文件输入，并优先覆盖 `mp4`、`mov`、`mkv`。

可作为后续处理入口的材料包括：

| 材料 | 首版定位 |
|---|---|
| 本地视频文件 | 必须支持 |
| 本地音频文件 | 可作为视频音频抽取后的等价输入预留 |
| 本地字幕文件 | 可作为转录不足时的补充材料预留 |
| 本地转录文本 | 可作为跳过转录环节的补充材料预留 |
| 在线公开视频链接 | 不直接进入 V2-lite 主链路；后续作为“提取到本地项目”的前置工具 |

## 在线视频边界

在线视频能力的长期方向是：先通过单独工具在合法授权和平台规则允许范围内提取标题、简介、章节、字幕、音频或视频到本地项目，再复用本地视频处理链路。

R0 / V2-lite 不承诺所有公开视频链接自动处理成功。失败时应提示用户补充本地视频、音频、字幕或转录文本。

## 权限与安全

- 只处理用户有权访问和分析的视频材料。
- 不绕过 DRM、付费墙、私密权限或登录限制。
- 私人或公司内部视频默认本地处理优先。
- 需要调用外部 API 或上传材料前，必须先获得用户确认。

## 验收关注点

- 能识别本地视频输入是否存在、格式是否在首版范围内。
- 对缺失材料给出明确说明。
- 对在线链接不做超出边界的成功承诺。
- 输出材料来源和用户后续动作建议。
