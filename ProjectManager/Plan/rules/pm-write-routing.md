# PM 写入路由规则

## 核心规则

1. 先改权威源，再改主管视图。
2. Plan 持有执行事实，不持有项目总览。
3. 索引只在生命周期变化时更新。
4. 关闭事项退出活跃视图。
5. 新 Plan 开工前先扫规格索引。

## 一致性检查触发

仅在以下场景运行 `python scripts/pm_sync_check.py`：

- 同一轮改了 2 个及以上权威源 / 索引源。
- 准备关闭里程碑或声明某块完成。
- 新建 / 归档 / 废弃 Plan、Spec、Issue 的入口关系。
- 版本启动 / 收口 / 切版本轴。
- Backlog 条目发生纳入、延期、落地归档或放弃归档。
