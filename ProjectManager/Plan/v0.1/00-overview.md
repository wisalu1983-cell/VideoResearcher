# v0.1 概览

> 状态：已收口
> 收口日期：2026-04-29

## 背景

需求调研已明确：VideoResearcher 的最低实用价值出现在 V2-lite，即本地视频到转录、索引、笔记、追问定位的最小闭环。v0.1 的任务不是完成全部能力，而是建立后续开发可依赖的管理、规格、模板和验收框架。

## 目标

1. 建立项目管理体系。
2. 定义视频项目产物目录和核心文件模板。
3. 建立长期规格 current spec 的分类。
4. 建立 QA 样本与验收方法。
5. 为本地视频处理脚本开发提供子计划入口。

## R0 收口决策

1. V2-lite 主链路以本地视频处理为基础；在线视频后续作为“提取到本地项目”的前置工具。
2. `video_index.yaml` 按预研原则直接落地初版字段，真实视频测试后再迭代。
3. `video_note.md` 采用混合版：默认快速消化，对高价值片段保留关键线索。
4. QA 样本先建立分类、选择标准和占位，等待后续提供具体视频。
5. 首轮验证环境为 Windows + NVIDIA 台式机，4070 Ti 作为主力基准，5060 作为兼容和备用验证。
6. API、公司模型和自费工具只作为人工批准 gate。
7. 质量阈值先采用定性分级，数值阈值等待真实样本测试后确定。

## 非目标

- 不在 v0.1 完成完整自动转录。
- 不承诺在线视频链接自动处理。
- 不做 OCR、抽帧、完整画面理解。
- 不做本地应用 UI。

## 收口快照

v0.1 已完成项目管理体系、视频项目产物模板、Specs current 分类与内容、QA 样本占位和验收方法、本地处理脚本子计划入口。

V1 入口已准备，下一阶段聚焦自动建索引：本地视频输入、FFmpeg 音频抽取、转录适配层、带时间戳转录、YAML 主索引、JSON 派生索引、处理日志和失败日志。
