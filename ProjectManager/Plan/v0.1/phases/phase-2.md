# Phase 2：单视频产物模板

定义每个视频处理项目的标准产物目录、索引模板、笔记模板和日志模板。

## R0 产出

模板入口：`ProjectManager/Templates/video_project/`

核心文件：

- `input/README.md`
- `transcript/transcript.srt`
- `transcript/transcript.json`
- `index/video_index.yaml`
- `index/video_index.json`
- `notes/video_note.md`
- `logs/process_log.md`
- `logs/failure_log.json`
- `logs/index_change_log.md`
- `DATA_CONTRACTS.md`

## 收口口径

模板覆盖预研中的标准交付文件。真实视频项目应复制模板后填充材料，不直接把模板目录当作样本执行结果。
