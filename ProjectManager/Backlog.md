### BL-009 · 端到端用户流程整合

- 状态：候选，计划在 V3 完成后启动
- 来源：V2-lite 真实样本追问测试（2026-05-20）
- 决策：2026-05-22 确认放在 V3 之后，V2-lite/V2-full/V3 阶段保持开发工具形态
- 背景：当前从视频到追问需要用户手动执行 4 条命令、理解 phase 概念、知道 model-size 含义、自行触发 Agent synthesis、解读 JSON 输出。流程各环节之间的衔接完全依赖用户对内部机制的了解。具体问题包括：(1) Phase 3 脚本只生成 draft，正式笔记需要用户在对话中手动让 Agent 合成，无任何提示；(2) 追问输出是 JSON 而不是人类可读回答；(3) model-size 选择需要用户了解 faster-whisper 模型体系和自身硬件条件；(4) 没有单一入口，两个脚本、多个 phase 标志需要用户自行编排。与 BL-006（本地应用 UI）不同：即使不做 UI，CLI 流程本身的衔接也需要改进。
