# QA 目录

`QA/` 是项目的单一 QA 根目录。

- `qa-leader-canonical.md`：QA 编排规范源
- `qa-system-methodology.md`：方法论与外部依据
- `capability-registry.md`：现有工具和脚本台账
- `templates/`：正式 QA 用例 / 报告模板
- `runs/`：正式 QA 执行产物与报告
- `scripts/`：可复用 QA 脚本
- `artifacts/`：临时证据，默认不入库

## 当前验收入口

- `v2-lite-acceptance-checklist.md`：V2-lite 输入、转录、索引、笔记、追问和可靠性验收清单
- `v2-lite-sample-plan.md`：首批样本视频分类、选择标准和占位计划
