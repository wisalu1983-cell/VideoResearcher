# V2-lite 验收清单

> 来源：`video_agent_requirements_research.md` §18
> 样本计划：`QA/v2-lite-sample-plan.md`

## 验收结论分级

| 等级 | 结论 | 允许用途 |
|---|---|---|
| A | 可精确追问 | 可作为 V2-lite 样本通过 |
| B | 可概览但不适合精确定位 | 可记录为降级通过，不计入完整闭环通过 |
| C | 不可可靠分析 | 不通过，保留失败证据 |

## 1. 输入可用

| ID | 检查项 | 通过标准 | 证据 |
|---|---|---|---|
| IN-001 | 本地视频格式 | 能处理 `mp4`、`mov`、`mkv` 范围内样本 | 输入文件与处理日志 |
| IN-002 | 视频时长 | 能处理 30 分钟到 3 小时视频 | 处理日志 |
| IN-003 | 主力环境 | 能在 Windows + NVIDIA 台式机跑通；4070 Ti 为基准，5060 为兼容验证 | 环境记录 |
| IN-004 | 材料边界 | 在线内容需先提取到本地项目，不直接绕过平台限制 | 输入来源说明 |

## 2. 转录可用

| ID | 检查项 | 通过标准 | 证据 |
|---|---|---|---|
| TR-001 | SRT 输出 | 生成 `transcript/transcript.srt` | 文件存在 |
| TR-002 | JSON 输出 | 生成 `transcript/transcript.json` | 文件存在且结构可读 |
| TR-003 | 语言可读性 | 中文、英文或中英混合内容整体可读 | 人工抽检记录 |
| TR-004 | 时间戳 | 时间戳能支持片段定位 | 抽样定位记录 |
| TR-005 | 质量分级 | 记录 A/B/C 转录质量和已知限制 | `process_log.md` 或转录 JSON |

## 3. 第一轮索引可用

| ID | 检查项 | 通过标准 | 证据 |
|---|---|---|---|
| IDX-001 | YAML 主索引 | 生成 `index/video_index.yaml` | 文件存在 |
| IDX-002 | JSON 派生索引 | 生成 `index/video_index.json`，且来自 YAML | 文件存在与导出记录 |
| IDX-003 | 完整脉络 | 覆盖视频主要章节 | 人工抽检 |
| IDX-004 | 高价值片段 | 高价值内容有时间段和标记 | 索引条目 |
| IDX-005 | 追问线索 | 索引包含可追问主题或问题 | `follow_up_index` |

## 4. 笔记可用

| ID | 检查项 | 通过标准 | 证据 |
|---|---|---|---|
| NOTE-001 | Markdown 笔记 | 生成 `notes/video_note.md` | 文件存在 |
| NOTE-002 | 快速消化 | 包含极简价值摘要和完整大纲 | 笔记内容 |
| NOTE-003 | 高价值片段 | 高价值片段保留核心结论和关键线索 | 笔记内容 |
| NOTE-004 | 可追溯 | 笔记时间段能追溯到索引或转录 | 抽样核对 |

## 5. 追问可用

| ID | 检查项 | 通过标准 | 证据 |
|---|---|---|---|
| QA-001 | 片段检索 | 用户问题能从索引中找到相关片段 | 问答记录 |
| QA-002 | 时间段输出 | 回答包含相关视频时间段 | 问答记录 |
| QA-003 | 支撑理由 | 回答说明片段为什么支撑结论 | 问答记录 |
| QA-004 | 转录回查 | 必要时能回查转录文本核对细节 | 问答记录 |
| QA-005 | 不足提示 | 索引依据不足时明确说明，不编造 | 问答记录 |

## 6. 可靠性与失败处理

| ID | 检查项 | 通过标准 | 证据 |
|---|---|---|---|
| REL-001 | 不编造 | 不输出视频中没有依据的确定性内容 | 抽检记录 |
| REL-002 | 不确定性 | 对低质量转录、时间戳错位或外部资料不足给出提示 | 日志与回答 |
| REL-003 | 外部资料区分 | 引入外部资料时区分视频内容和外部补充 | 回答记录 |
| REL-004 | 失败日志 | 失败时写入 `logs/failure_log.json` | 文件与内容 |
| REL-005 | 中间结果 | 失败时保留已完成中间结果 | 输出目录 |

## R0 备注

本清单先使用定性分级。时间戳误差、转录错误率、追问命中率等数值阈值，等待真实样本测试后再固化。
