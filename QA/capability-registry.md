## 项目模块划分

| 模块 ID | 模块名称 | 覆盖范围 | 默认 QA 深度 |
|---|---|---|---|
| SRC | 输入与材料 | 本地视频、字幕、转录文本、在线视频可行性 | L1 |
| TRN | 转录 | 音频抽取、转录、时间戳、分段 | L2 |
| IDX | 索引 | YAML 主索引、JSON 导出、粒度与字段 | L2 |
| QNA | 追问 | 检索片段、回答依据、回查转录 | L2 |
| EXT | 外部资料 | 来源可靠性、必要性、区分视频与外部补充 | L2 |
| FAIL | 失败处理 | 失败日志、中间结果、用户下一步动作 | L2 |
