# VideoResearcher 开发文档流

本项目的正式开发文档应优先围绕“视频处理工作流是否可靠、可追溯、可复盘、可继续追问”来组织，而不是只描述脚本怎么跑。

## 专业质量门

| 质量门 | VideoResearcher 侧重点 |
|---|---|
| 输入边界 | 本地文件、字幕、转录文本、在线视频链接可行性 |
| 处理链路 | FFmpeg、转录工具、分段、时间戳、索引生成 |
| 数据契约 | YAML 主索引、JSON 派生索引、Markdown 笔记、日志字段 |
| 可靠性 | 不编造、低质量转录提示、不确定性提示、外部来源标注 |
| 失败恢复 | 保留中间结果、失败类型、用户下一步动作 |
| QA 映射 | 样本视频、产物结构校验、追问定位、时间戳准确性 |
